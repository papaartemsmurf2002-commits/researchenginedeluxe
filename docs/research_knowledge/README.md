# Research Knowledge Catalog

This directory stores non-authoritative research knowledge that can help future
agents design falsifiable experiments.

These files are not implementation roadmaps, candidate evidence, promotion
evidence, or live trading instructions. Treat them as hypothesis maps and
backtest-design references. Every idea still needs repo-native data manifests,
point-in-time features, cost/funding/slippage accounting, split-safe
validation, ablation evidence, and research gates before it can influence any
candidate decision.
