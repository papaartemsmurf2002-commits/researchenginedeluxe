Regime Filters And Parameters

Closed-bar regime filters for corridor/chop rejection. Unchecked components are ignored by visual replay and excluded from the optimizer family. Goldilocks uses Binance OHLCV enrichment for VWAP because current TradingView chart exports do not include volume.

Lag-1 autocorrelation of 15m close-to-close log returns. Negative values indicate whipsaw/mean reversion.

Short-window return volatility divided by long-window volatility. Low ratio means compressed corridor behavior.

Causal SciPy Butterworth bandpass on returns. High cycle energy with weak trend slope is treated as cyclical/ranging mode.

Decision Rule

Reject when at least two enabled filters flag chop/cycle mode. If only one filter is enabled, that filter can reject alone. ACF+HVR trend override can pass strong directional regimes.

Net close displacement divided by total close-to-close path over the lookback. Low values flag churn.

UTC-day anchored HLC3 VWAP using Binance 15m volume. Longs require price above VWAP; shorts require price below VWAP.

Percentile rank of rolling log-return volatility. Used as a kinetic-energy band, not a hard volatility-is-good rule.

Decision Rule

All enabled Goldilocks components must pass. Missing selected components reject as insufficient history and are reported separately from strategic rejections.

Exit logic is fixed by the selected research profile and is not optimized.
